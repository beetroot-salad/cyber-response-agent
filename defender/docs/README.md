# Defender documentation

Start with the [development map](development-map.md) to locate code and the relevant development guide.

- `decisions/` records product design decisions.
- `archive/` preserves historical product designs.
- Runtime, learning, storage, and operator guides live in this directory.

The [VPS deployment design](decisions/vps-compose-deployment.md) records the
two-host Compose architecture, identity, execution boundaries, storage, and
operations. Database-backed findings remain a proposal in that document.

The repository-wide [engineering principles](../../docs/principles.md) also apply. Playground documentation lives under `playground-v2/docs/`.
