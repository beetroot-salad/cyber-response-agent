## The fixture argues with its own label

The attack runner leaves simulation markers in the world: the key it plants is literally
`AAAAB3NzaC1yc2EAAAAD_fake_key_0` with comment `attacker@elsewhere`, the container has an
84-day history of 36 authorized_keys writes across 38 Falco rules, and `/opt/soc-playground/
seed-users.py` is on the host. Every A run found this. Three of them closed **benign**
on "this is a security-training simulation environment" — true of the world, and exactly the
close the label calls a miss: nothing in CMDB, change-mgmt or the ticket system authorizes
the write, and the run's job is to disposition the activity, not to recognise the lab.

C found the same markers and would not close benign on them. C-t2's ceiling names it:
*"simulation markers strongly suggest training environment, but no authoritative system
confirms"* → `inconclusive`. That is the discipline `defender/SKILL.md` asks for ("default to
escalation when uncertain") and it is the difference between the arms on this fixture: **A
took the simulation exit 3 times in 4; C never did.** On a 3-class label both score 1/4, so
the label alone hides the asymmetry; the false-negative count does not.

Whether "benign, it's a lab" is a defensible verdict is a question about the playground, not
about the clerk — the markers are a fixture-capture artifact worth scrubbing before this alert
is used as a held-out case.

## The crash (C-t4), honestly

Fireworks returned a 503 for `kimi-k2p6` inside a clerk call (the 4th `record`, 4 min in).
The throwaway `record` tool catches validator refusals but not provider errors, so the
exception ended the run: no report, counted as not concluded. A production version keeps
MAIN's prose, tells MAIN the rows are pending, and moves on. The three other C runs cost
$0.64–1.03; the crash is the only exit≠0 of the sixteen trials and it is the clerk arm's.

## C-t3 `unresolved`

Host-terminated: the challenge review (the existing close gate, same in both arms) found the
confident finding unsettled and the evidence gathered could not discriminate. The gate did
its job; the record validates.
