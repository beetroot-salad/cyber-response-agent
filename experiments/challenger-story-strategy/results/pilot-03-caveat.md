# What pilot 03 does not establish

The lens arm won on unsettled requirements 14 to 3 to 2. That comparison does **not** isolate
composition strategy, for a reason worth stating before anyone builds on it.

**The lens arm gets twelve independent asks for unsettled items; the seed gets one.** Each
per-lead check is explicitly prompted for "anything the account needs that this payload does
not show either way", and the fold is forbidden from dropping any of them. A floor near twelve
is close to guaranteed by construction. That is sampling breadth, not necessarily better
reasoning about the case.

The controlled test is cheap and has not been run: **ask the seed arm for a comparable number
of unsettled requirements in one call.** If a single call can produce fourteen of similar
quality, the twelve extra calls buy nothing and the whole result reduces to the tail-spec fix,
which is free.

Three further limits:

- **n=1 fixture, one trial per arm, one direction.** The fixture pool has exactly one benign
  run, so this is also the only FN-hunt case available.
- **No quality verdict.** The counts are structural. The reframed objective is
  consistency-at-disposition, and nothing has judged the three round-3 stories against it. A
  blind judge on that criterion is the next step, not a scale-up.
- **Padding is present and unmeasured.** Fourteen exceeds the number of real discriminators in
  this case; several entries are trivia. Nothing distinguishes a discriminating requirement
  from a filler one yet, which is exactly what a ranked or capped list would need.
